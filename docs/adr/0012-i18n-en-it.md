# ADR-0012: Languages — English and Italian, packaged, with an in-app override

- **Status:** Accepted
- **Date:** 2026-10-19
- **Deciders:** project owner

## Context

The owner's users are Italian and English speakers; `chrome.i18n` follows only the browser's language and cannot be switched in the UI.

## Decision

Package all interface and help strings for **English and Italian** in `i18n.js`, with a **Language** selector (browser default, English, Italiano) stored in `feedGuardLanguageV1` and shared by popup and help. `_locales/` holds only the extension name and description, which the browser shows in its own language. Diagnostic JSON keys stay English.

## Alternatives considered

- **`chrome.i18n` only.** Rejected: no in-app override.

## Consequences

- Every string exists in both languages; a new string is added to both in the same change.

## Validation

- `tests/ui.test.cjs` asserts the EN and IT key sets are equal and every page key exists.
